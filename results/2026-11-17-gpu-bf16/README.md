# GPU Codec BF16 基准测试（2026-11-17）

RTX 5090；KV-aware 分页；CPU 编码单线程；GPU 每批最多 256 页。两个完整数据集覆盖 20 个 GPU 配置，另保留兼容的 CPU 解码结果。所有结果逐页通过无损校验。

DeepSeek：形状 `[43,15095,512]`，每页 128 token、128 KiB；每层保留最后不足一页的尾部。该 BF16 输入由原生 FP8 数据解量化得到，无损校验针对存储的 BF16 字节，不代表恢复量化前数据。

Qwen：形状 `[16,2,1,4,8192,256]`，每页 256 token、1 MiB，保留完整 K/V 逻辑页面。

压缩率为原始字节数除以完整压缩帧字节数。编码速度单位为 MiB/s，GPU 解码速度单位为 GiB/s（1 GiB = 1024 MiB）。Codec 调用计时排除初始化、预校准、预热、显存传输、封装与校验；调用内部的必要分配和处理仍计入。页面速度另含准备、封装及传输等开销。

GPU Codec 速度使用实际执行流上的 CUDA Event 包围官方 API 调用，仍可能包含调用内部的分配与提交间隙，不等于纯内核峰值。页面吞吐不包含输入文件 I/O、KV 页面构造、帧缓存写盘或外层逐字节比较，也不代表完整部署链路吞吐。

每个 Codec 遍历一次完整数据集，每种页面/批量形状先预热，再汇总测量时间；表中数据不是多次独立运行的均值或硬件峰值。CPU/GPU 兼容解码共享同一编码帧与编码测量。SplitZip 每个数据集只用首个页面预校准，并从 Codec 吞吐计时中排除。

运行环境与依赖版本见 `environment.json`；开始与结束时间使用 UTC，换算北京时间需加 8 小时。

代码提交：`6ed12686722f79efd76e837527fd4b38141aff9f`。GPU 校验页面共 111,720；包含兼容 CPU 解码共 167,580。

## 文件

- `gpu_results.csv`：40 条 GPU 路径完整指标。
- `result.csv`：全部 60 条结果，含 20 条兼容 CPU 解码结果。
- `heatmap.html`：可筛选的独立 HTML 报告。
- `input_manifest.json`：输入文件 SHA-256 与配置列表。
- `run_metadata.json`：起止时间、硬件状态和线程参数（省略机器专用 GPU UUID）。
- `environment.json`：实际软件版本、输入布局和安装 Manifest 校验和。
- `settings.example.txt`：可移植测试配置，使用框架管理的 CUDA 13 环境。
- `sha256.json`：本目录发布文件的 SHA-256。
